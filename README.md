## Vedere il sito in locale
Apri `index.html` nel browser (doppio click). Nessun server necessario.

## Deploy su GitHub Pages
1. Crea un repository (es. `Diacoin/alassio-drink`).
2. Carica **il contenuto di questa cartella** nella radice del repo.
3. Settings → Pages → *Deploy from a branch* → `main` / `root`.
4. (Opzionale) Dominio personalizzato: file `CNAME` con il dominio + record DNS presso il registrar.
